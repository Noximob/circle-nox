# Circle · Nox Imóveis

Dashboard da consultoria Circle para a Nox Imóveis.

- **Enquete** — as 4 tarefas do mapeamento (Valores, Missão, Visão, Metas), com comentário e nota de 1 a 5
- **Missão, Visão e Valores** — o institucional definido
- **Metas** — R$ 28 mi → R$ 56 mi (12 meses) → R$ 100 mi (24 meses)
- **Kanban** — organização das próximas etapas

Página única, sem build. O visual segue o design system do CRM da Nox.

## Rodar local

Abrir o `index.html` no navegador, ou servir a pasta:

```bash
python -m http.server 8000
```

## Deploy

Netlify — publica a raiz do repositório, sem comando de build.
